\# Project Overview: DevNotes



\- \*\*Tên ứng dụng:\*\* DevNotes

\- \*\*Nền tảng:\*\* Mobile App (Flutter)

\- \*\*Mục tiêu:\*\* Xây dựng ứng dụng ghi chú Markdown dành cho lập trình viên (Developer-centric).

\- \*\*Core USP (Unique Selling Proposition):\*\* - Local-first: 100% dữ liệu nằm trên máy người dùng dưới dạng file `.md`. Không dùng Backend/Database truyền thống (như Firebase/Supabase).

&#x20; - BYOC (Bring Your Own Cloud) via Git: Đồng bộ dữ liệu bằng cách commit/push trực tiếp lên Private GitHub/GitLab Repository của người dùng. Chi phí server = 0.

&#x20; - Hỗ trợ render Markdown chuẩn và Code Snippet có Syntax Highlighting.
